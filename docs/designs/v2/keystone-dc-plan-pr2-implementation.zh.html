Keystone V2 / PR-2 / 2026-07-09

Hilbert 数采计划投影实施细节

PR-2 的核心矛盾：Keystone 需要消费 Hilbert dc_plan 作为生产主对象， 但不能在这一刀里切换 task 生成、上传协议或本地计划模型。

对象dc_plan 只镜像 Hilbert 计划
同步单 Workspace 手动分页同步
执行task / episode 只预留字段
前端只读列表 + 手动同步按钮
01

背景与判断

PR-1 已经把 Keystone 的 Workspace 来源规则切到 Hilbert 投影：Keystone 不创建、不编辑、不删除 Workspace， 并保留 id=0 的 default workspace 支撑本地采集闭环。

PR-2 不继续扩展 order/batch，而是把 Hilbert 数据采集计划接入 Keystone。Hilbert 代码中 dc_plan.id 是 bigint 主键，raw data 注册也要求 workspaceId 和 dcPlanId 同时存在并归属一致。

决策：Keystone 的 dc_plan 表只保存 Hilbert 计划投影，dc_plan.id 直接等于 Hilbert dc_plan.id；本地计划以后进入独立的 local_dc_plan。
02

目标与非目标

本 PR 要做

  • 新增 dc_plan Hilbert 投影表。
  • 删除 workspaces.upload_enabled，不再控制 Workspace 级上传资格。
  • 新增 Hilbert dc-plan/query client 和同步 service。
  • 提供 GET /dc-plans 只读列表。
  • 提供单 Workspace 手动同步接口。
  • 给 tasks / episodes 预留计划字段。
  • Synapse 新增 /admin/dc-plans 只读页。

本 PR 不做

  • 不创建 Keystone 本地计划。
  • 不实现 dc_plan 详情 API。
  • 不切换 order/batch task 生成 runtime。
  • 不改上传 worker 或 Hilbert raw data payload。
  • 不处理 robot / workstation / collector 的 workspace 归属。
  • 不删除 order/batch、factory、scene、SOP 等旧 runtime。
03

数据模型

dc_plan Hilbert 投影表

表名、字段名和必填约束尽量跟 Hilbert 当前 dc_plan 对齐。 Keystone 只追加同步排障字段和本地投影行时间。 

CREATE TABLE IF NOT EXISTS dc_plan (
    id BIGINT PRIMARY KEY,
    workspace_id BIGINT NOT NULL,
    name VARCHAR(100) NOT NULL,
    description VARCHAR(200),
    dc_factory_id BIGINT NOT NULL,
    dc_service_provider_id BIGINT NOT NULL,
    operator VARCHAR(100) NOT NULL,
    dc_project_id BIGINT NOT NULL,
    dc_task_id BIGINT NOT NULL,
    dc_device_id BIGINT NOT NULL,
    dc_type VARCHAR(100) NOT NULL,
    dc_date DATE NOT NULL,
    target_count BIGINT NOT NULL,
    cur_count BIGINT NOT NULL DEFAULT 0,
    target_duration BIGINT NOT NULL,
    cur_duration BIGINT NOT NULL DEFAULT 0,
    created_by VARCHAR(100) NOT NULL,
    created_time TIMESTAMP NOT NULL,
    updated_by VARCHAR(100),
    updated_time TIMESTAMP NULL,
    raw_payload JSON DEFAULT NULL,
    last_synced_at TIMESTAMP NULL,
    sync_error TEXT,
    local_created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    local_updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP NULL,
    INDEX idx_workspace (workspace_id),
    INDEX idx_name (name),
    INDEX idx_dc_type (dc_type),
    INDEX idx_operator (operator),
    INDEX idx_dc_date (dc_date),
    INDEX idx_last_synced (last_synced_at),
    INDEX idx_deleted (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
决策说明
id直接使用 Hilbert dc_plan.id，不再使用本地自增映射。
nameKeystone 只建普通索引，不复制 Hilbert 的全局唯一约束。
source不需要。dc_plan 天然只表示 Hilbert 投影。
外键不加数据库外键，业务层校验 Workspace 存在且 source='hilbert'。

Task / Episode 预留字段

ALTER TABLE tasks
  ADD COLUMN dc_plan_id BIGINT NULL,
  ADD COLUMN local_dc_plan_id BIGINT NULL,
  ADD INDEX idx_dc_plan (dc_plan_id),
  ADD INDEX idx_local_dc_plan (local_dc_plan_id);

ALTER TABLE episodes
  ADD COLUMN dc_plan_id BIGINT NULL,
  ADD COLUMN local_dc_plan_id BIGINT NULL,
  ADD INDEX idx_dc_plan (dc_plan_id),
  ADD INDEX idx_local_dc_plan (local_dc_plan_id);

PR-2 不写入这些字段，不加互斥 CHECK。dc_plan_id 指向 Hilbert 投影； local_dc_plan_id 预留给未来 local_dc_plan。

删除 workspaces.upload_enabled

Keystone 不再维护 Workspace 级上传资格开关。default workspace 仍不可进入 Hilbert raw data / dataset 创建路径； Hilbert workspace 是否可上传由 Hilbert API 权限和计划归属校验决定。

04

同步流程

Synapse 点击同步
Keystone 校验 workspace
Hilbert 分页 query
整批校验计划
事务 upsert

入口

POST /api/v1/workspaces/:workspace_id/dc-plans/sync

Workspace 校验

  • workspace_id=0 直接拒绝。
  • 本地 workspaces 必须存在、未删除、source='hilbert'。
  • 不检查 upload_enabled，该字段已删除。

Hilbert 分页

GET /v1/data-collection/dc-plan/query?workspaceId=123&pageNum=1&pageSize=200
GET /v1/data-collection/dc-plan/query?workspaceId=123&pageNum=2&pageSize=200
  • 内部同步复用 Hilbert pageNum/pageSize。
  • 每页 pageSize=200，循环直到拉完。
  • Keystone 本地列表 API 不暴露 Hilbert 分页格式。

原子性

  • 任一计划非法，本次同步整体失败，不 partial upsert。
  • 非法包括 id<=0、workspaceId 不等于当前 workspace、必填字段为空或计数非法。
  • 如果已存在同 id 但 workspace_id 不同，整体失败。
  • 本次未返回的计划不删除、不软删。
  • 整体失败只返回错误并打日志，不写同步日志表。

响应

{
  "workspace_id": 123,
  "synced_count": 37,
  "page_count": 2,
  "last_synced_at": "2026-07-09T12:34:56Z"
}
05

Keystone API

只读列表

GET /api/v1/dc-plans?workspace_id=123&limit=20&offset=0
GET /api/v1/dc-plans?workspace_id=123&name=ego&dc_type=ego&operator=alice&dc_date=2026-07-09
  • workspace_id 必填，不传返回 400。
  • name 模糊搜索。
  • dc_type、operator、dc_date 精确匹配。
  • dc_date 使用 YYYY-MM-DD，非法日期返回 400。
  • 返回 Keystone 标准 items/total/limit/offset/hasNext/hasPrev 分页包装。
  • 记录字段使用 snake_case；ID 字段使用数字，贴近 Hilbert。

不提供的接口

GET    /api/v1/dc-plans/:id
POST   /api/v1/dc-plans
PUT    /api/v1/dc-plans/:id
DELETE /api/v1/dc-plans/:id
06

Synapse 页面

新增 /admin/dc-plans 独立只读页。页面顶部选择 Hilbert workspace， 选择后加载 Keystone 本地已有投影；用户点击同步按钮才触发 Hilbert 同步。

区域行为
Workspace 选择只显示 source='hilbert' 的 workspace，不显示 default。
同步按钮调用 POST /workspaces/:workspace_id/dc-plans/sync，成功后刷新列表。
列表分页使用 Keystone limit/offset，默认每页 20。
详情PR-2 不做抽屉或详情页。
Workspace 状态页删除 upload_enabled 相关列、标签和文案。

列表列

  • id
  • name
  • dc_type
  • dc_date
  • operator
  • target_count / cur_count
  • target_duration / cur_duration
  • last_synced_at
07

实施与验证

实施顺序

  1. 更新 V2 baseline schema：新增 dc_plan，删除 workspaces.upload_enabled，给 task / episode 加计划字段。
  2. 调整 workspace handler、response、测试和 Synapse workspace 状态页，移除 upload_enabled。
  3. 新增 Hilbert dc-plan client DTO 和分页 query 方法。
  4. 新增 dc-plan sync service，完成校验、分页、事务 upsert。
  5. 新增 GET /dc-plans 和 sync handler。
  6. 更新 Swagger。
  7. 新增 Synapse /admin/dc-plans 页面和 API wrapper。

最低测试集

  • 同步拒绝 workspace_id=0。
  • 同步拒绝非 Hilbert workspace / 不存在 workspace。
  • Hilbert 分页同步成功，upsert 多页计划。
  • Hilbert 返回非法计划时整体失败且不 partial upsert。
  • GET /dc-plans 必须带 workspace_id，并覆盖筛选。
  • workspaces.upload_enabled 从响应、Swagger、测试期望和 Synapse 展示中移除。
